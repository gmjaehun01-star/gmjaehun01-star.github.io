## 2. 내용 고치기

`index.html` 파일을 메모장이나 VS Code로 열면, 위쪽에 다음과 같은 부분이 있습니다.

    <script id="content">
    const SITE = {
      ...
    };
    </script>

**이 안쪽만 고치시면 됩니다.** 아래쪽의 style, script 부분은 건드리지 않으셔도 됩니다.

### 자주 고치실 항목

| 고치고 싶은 것 | 찾을 곳 |
|---|---|
| 도입 문의 주소 | `applyUrl` |
| 첫 화면 문구 | `heroTitle`, `heroText` |
| 첫 화면에서 흘러가는 자막 예시 | `heroDemo` |
| 성능 수치 | `stats` |
| 도입 기관 이름 (자동 슬라이드) | `refs` |
| 제품 설명·기능 | `products` 안의 각 항목 |
| 소개 영상 | `products` 안의 `youtube` |

### 유튜브 영상 연결하는 법

유튜브에 영상을 올린 뒤 주소를 봅니다.

    https://www.youtube.com/watch?v=AbCdEfGhIjK
                                    ^^^^^^^^^^^  이 부분(11자리)만 복사

`youtube:""` 를 `youtube:"AbCdEfGhIjK"` 로 바꾸면 페이지에서 바로 재생됩니다.
비워두면 "소개 영상 준비 중입니다" 안내가 표시됩니다.

### 도입 기관 이름 넣는 법

`refs` 목록에 기관명을 넣으면 자동으로 옆으로 흘러갑니다.
**공개 동의를 받은 기관만** 실제 이름으로 바꾸시고, 나머지는 `○○대학교` 형태로 두시면 됩니다.

    refs: [ "○○대학교 국제처", "○○교육청", ... ]

개수는 자유롭게 늘리거나 줄일 수 있습니다. 8개 이상이면 자연스럽게 흘러갑니다.

## 3. 페이지 구성

- `#/` — 전체 소개 (첫 화면, 제품 4종, 성능, 도입 현황, 무료 체험)
- `#/caption` — TkitaCaption
- `#/talk` — TkitaTalk
- `#/mobile` — TkitaMobile
- `#/meet` — TkitaMeet

제품별 주소를 그대로 복사해서 메일이나 제안서 QR에 쓰실 수 있습니다.

## 4. 이미지 교체

`images` 폴더의 파일을 같은 이름으로 덮어쓰면 교체됩니다.
새 이미지를 추가하실 때는 `images` 폴더에 넣고, `products` 안의 `shots` 목록에
`["images/파일명.png", "설명글"]` 형태로 한 줄 추가하시면 됩니다.

## 5. 도입 기관 로고 (현재 82곳 등록됨)

로고 파일은 `images/refs/ref-01.webp` ~ `ref-82.webp` 로 들어 있고,
`index.html` 의 `refs` 목록에 파일명과 기관명이 짝지어 있습니다.

    refs: [
      { logo:"images/refs/ref-01.webp", name:"건국대학교" },
      ...
    ]

- **빼실 기관** : 해당 줄을 지우시면 됩니다 (파일은 남겨두셔도 무방)
- **추가하실 기관** : 로고를 `images/refs` 에 넣고 줄을 하나 더 쓰시면 됩니다
- **순서 변경** : 줄 순서를 바꾸시면 그대로 반영됩니다
- 목록은 자동으로 위아래 두 줄로 나뉘어 서로 반대 방향으로 흘러갑니다

### (참고) 로고를 직접 만들 때

1. 로고 이미지를 `images/refs` 폴더에 넣습니다. (PNG 권장, 배경이 투명하면 가장 깔끔합니다)
2. `index.html` 의 `refs` 목록에 아래처럼 한 줄 추가합니다.

       refs: [
         { logo:"images/refs/univ-a.png", name:"○○대학교" },
         { logo:"images/refs/office-b.png", name:"○○교육청" },
         "○○고등학교"
       ]

글자와 로고를 섞어 넣어도 됩니다. 로고가 있는 기관은 로고로, 없는 기관은 글자로 표시됩니다.

### 로고 이미지 만들 때

- **가로로 긴 형태**가 가장 잘 맞습니다. 세로 100~200px 정도면 충분합니다.
- 배경은 **투명(PNG)** 이 가장 좋고, 흰 배경도 괜찮습니다.
- 너무 작거나 글씨가 많은 로고는 흘러갈 때 읽히지 않으니, 심볼+기관명이 함께 있는 형태를 쓰세요.
- 8개 이상 넣으면 빈틈 없이 자연스럽게 이어집니다.

### 주의

기관 로고는 **해당 기관의 사용 동의를 받은 경우에만** 올리셔야 합니다.
동의 전에는 `"○○대학교"` 처럼 글자로 두시면 됩니다.


## 6. Google Analytics(GA4) 연결

`index.html` 맨 위 `gaId:""` 에 측정 ID를 넣으면 바로 켜집니다.

    gaId: "G-AB12CD34EF",

넣는 순간부터 아래 항목이 자동으로 기록됩니다.
- 페이지별 조회수 (제품 페이지, 기관별 페이지 포함)
- 버튼 클릭 : 무료 사용(cta_trial), 기관 도입 문의(cta_apply), 전화(contact_tel), 메일(contact_mail)

### 광고 링크 추적 (UTM)
광고 연결 주소에 `?utm_source=…&utm_medium=…&utm_campaign=…` 를 붙이면 GA에서 광고별 유입을 볼 수 있습니다.
`#/` 앞에 붙여야 합니다. 예) `https://tkita.kr/?utm_source=naver&utm_medium=cpc&utm_campaign=univ#/univ`
GA의 **보고서 → 획득 → 트래픽 획득** 에서 세션 소스/매체·캠페인으로 확인합니다.

## 7. 기관 도입 문의 폼을 페이지 안에 넣기

지금은 문의 버튼을 누르면 MS Forms 가 새 창으로 열립니다.
페이지 안에서 바로 작성하게 하려면 `formEmbed` 에 삽입 주소를 넣으세요.

1. MS Forms 에서 해당 양식 열기 → 오른쪽 위 **응답 수집** 클릭
2. 아이콘 중 **< >  (삽입)** 선택
3. 나오는 코드에서 `src="..."` 안의 주소만 복사
4. `formEmbed: "복사한 주소"` 로 입력

넣으면 문의 버튼이 `#/contact` 페이지로 연결되고, 그 자리에서 작성됩니다.

## 8. 기관 유형별 페이지

- `#/univ` 대학기관  ·  `#/school` 초·중·고  ·  `#/public` 공공기관

광고 그룹별 도착 주소로 쓰시면 됩니다. 내용은 `segments` 에서 고칩니다.

## 9. 자주 묻는 질문 켜기

`faq` 의 `show:false` 를 `true` 로 바꾸면 첫 화면 하단과 `#/faq` 에 표시됩니다.
문항과 답변은 `items` 에서 고칩니다. 답변을 채우기 전에는 `false` 로 두세요.

## 10. 주소를 바꿨을 때

`siteUrl` 과, `index.html` 위쪽 `og:image` / `og:url` 두 줄의 주소를 함께 바꿔 주세요.
카카오톡·문자로 링크를 보낼 때 뜨는 미리보기가 이 주소를 씁니다.

`robots.txt` 의 `Sitemap:` 줄과 `sitemap.xml` 의 `<loc>` 주소도 같이 바꿔야 합니다.
`index.html` 위쪽의 `<link rel="canonical">` 주소와 `application/ld+json` 안의 `"url"` 도 같이 바꿔 주세요. (구글 검색 결과에 사이트 이름을 "Tkita"로 보여 주는 용도)
주소가 바뀌면 네이버 서치어드바이저·구글 서치콘솔에 새 주소를 사이트로 추가하고 사이트맵을 다시 제출합니다.
(네이버 소유확인 코드는 주소마다 따로 발급됩니다.)

## 13. 메인 소개 영상 (순서대로 이어 재생)

`index.html` 의 `intro` 에서 관리합니다.

    intro: {
      title: "Tkita, 3분이면 이해됩니다",
      lead:  "제품이 실제로 어떻게 움직이는지 ...",
      videos: [
        ["GY3_QZDO3CQ", "Tkita 소개"],
        ["MKyQ3UiLShI", "실제 사용 장면"],
        ["e065sW8TdF8", "활용 사례"]
      ]
    }

- `["유튜브11자리", "버튼에 표시될 제목"]` 형태로 줄을 늘리거나 줄이면 됩니다
- 재생 버튼을 한 번 누르면 1편 → 2편 → 3편 → 다시 1편 순으로 계속 이어집니다
- 아래 제목 버튼을 누르면 그 편부터 이어서 재생됩니다
- `videos: []` 로 비우면 이 구간 자체가 화면에서 사라집니다

## 14. 제품 페이지 대표 화면

제품의 `youtube` 가 비어 있으면 **`shots` 의 첫 번째 이미지가 대표 화면**으로 크게 표시되고,

`youtube` 에 주소를 넣는 순간 그 자리가 영상으로 바뀌고,
빠졌던 이미지는 "실제 화면" 목록으로 돌아갑니다. 다른 수정은 필요 없습니다.

## 16. 404 페이지

없는 주소로 들어오면 안내 화면이 나옵니다. 두 가지가 준비되어 있습니다.

- `404.html` — 잘못된 파일 경로로 들어왔을 때 (예: /abc)
- `index.html` 안의 404 화면 — 잘못된 해시 주소일 때 (예: /#/abc)

문구를 고치시려면 `404.html` 을 직접 열어 수정하시면 됩니다.

## 17. 도입 기관 로고 불러오는 시점

첫 화면이 뜨는 속도를 위해서이며, 따로 설정하실 것은 없습니다.

## 19. 측정 결과

`index.html` 의 `proof` 에서 관리합니다.

    proof: {
      barLabel: "번역 품질 · BLEU 점수",
      bars: [
        ["Tkita",         76, true],     ← true 는 파란색 강조
        ["구글 번역 API",  69, false]
      ],
      langs: [ ["77개","음성인식 지원 언어"], ["133개","번역 지원 언어"] ],
      ...
    }

- 막대는 100점 만점 기준 길이로 그려지고, 화면에 들어올 때 차오르는 효과가 있습니다
- 강조(true)와 비강조(false) 점수 차이가 자동으로 "▲ ○점 높음" 표시로 나옵니다
- 새 시험 결과가 나오면 `bars` 에 줄을 추가하거나 새 항목을 만들어 주시면 됩니다


## 20. 영문판

### 언어가 정해지는 순서
1. 주소 끝에 `?lang=en` 또는 `?lang=ko` 가 붙어 있으면 그 언어
2. 방문자가 전에 상단 버튼으로 골랐던 언어 (브라우저에 기억됨)
3. 그 외에는 모두 한국어

브라우저 언어가 한국어가 아닌 방문자에게는 화면 맨 위에 **"This site is in Korean. View in English"** 안내 띠가 나옵니다.
누르면 영문으로 바뀌고, × 를 누르면 한국어로 기억되어 다시 나오지 않습니다.
(예전에는 외국어 브라우저면 자동으로 영문을 보여줬는데, 구글 검색 로봇이 영문 화면을 읽어 검색 결과가 영문으로 나오는 문제가 있어 바꿨습니다.)

상단 `EN / 한국어` 버튼으로 언제든 바꿀 수 있습니다.

### 링크를 영문판으로 보내고 싶을 때
해외 파트너에게 보낼 때는 주소 뒤에 `?lang=en` 을 붙이세요.

    https://tkita.kr/?lang=en
    https://tkita.kr/?lang=en#/meet

### 영문 내용 고치기
`index.html` 에서 `const SITE_EN = {` 부분을 찾으시면 됩니다.
한국어판(SITE)과 같은 구조이며, **여기 적은 항목만 영문으로 바뀌고 나머지는 한국어판을 그대로 씁니다.**
이미지 · 유튜브 · 연락처 · 도입 기관 로고는 공통이라 따로 적지 않습니다.

- 제품은 `products: { caption: {...}, talk: {...} }` 처럼 **제품 id 별로** 적습니다
- 기관 유형도 `segments: { univ: {...} }` 처럼 id 별로 적습니다

### 버튼·제목 같은 화면 공통 문구

### 바닥 운영 표기 문구
바닥 주소·연락처 아래에 "이 사이트는 Tkita 총판사 ㈜드림아이티가 운영합니다." 문구가 나옵니다.
문구는 `UI` 의 `f_op` 항목(한국어 `ko`, 영문 `en`)에서 고치시면 됩니다. `{seller}` 자리에는 총판사 이름(`seller`)이 자동으로 들어갑니다.

### 영문 문의 양식
지금은 영문판에서도 한국어 MS Forms 로 연결되며, "양식이 한국어로 되어 있으니 메일로 문의해도 된다"는 안내가 함께 나옵니다.
영문 양식을 따로 만드시면 `SITE_EN` 의 `// applyUrl:` 줄 앞 `//` 를 지우고 주소를 넣으시면 됩니다.
